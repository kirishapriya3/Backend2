# 🔐 User Authentication & Authorization API

A secure REST API built using **Node.js, Express, MongoDB, JWT, and bcrypt** that supports:

- ✅ User Registration
- ✅ User Login
- ✅ JWT Authentication
- ✅ Role-Based Authorization (Admin Access)
- ✅ Protected Routes

---

## 🚀 Tech Stack

- Node.js
- Express.js
- MongoDB (Atlas)
- Mongoose
- JWT (jsonwebtoken)
- bcrypt
- dotenv
- Nodemon
